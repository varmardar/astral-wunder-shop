# 🔮 AstralWunder – Fake-Esoterik-Shop (Satire)

Ein rein statischer Spaß-Shop für GitHub Pages. Nichts funktioniert wirklich – jeder Kaufversuch scheitert mit einer esoterischen Ausrede.

## Hosten auf GitHub Pages
1. Neues Repository auf GitHub anlegen (z. B. `astral-wunder-shop`).
2. Alle Dateien dieses Ordners hochladen (oder `git push`).
3. **Settings → Pages → Source: „Deploy from a branch“**, Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. 1 Minute ist der Shop unter `https://<dein-name>.github.io/astral-wunder-shop/` erreichbar.

## Struktur
```
index.html    Seite
faq.html      Fake-FAQ mit Frage-ans-Universum
agb.html      Fake-AGB & Impressum
checkout.html Fake-Kasse, die immer dramatisch scheitert
style.css     Design
products.js   Produkte (hier neue hinzufügen)
chat.js       Fake-Support-Chat mit Schamane Rüdiger
cookies.js    Fake-Cookie-Banner (Dinkelkekse)
fomo.js       Fake-Verkaufsdruck (Popups, Countdown, Lagerbestand)
script.js     Fake-Warenkorb, Detailansicht, Suche
images/       Produktbilder (SVG – gerne durch eigene Fotos ersetzen)
```

## Eigene Produkte
Einfach in `products.js` einen Eintrag ergänzen und ein Bild in `images/` legen.

⚠️ Satire. Kein echter Shop, keine echten Produkte, keine Heilversprechen.
